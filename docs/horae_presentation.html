09. GET STARTED IN OMARCHY
09 / 09
QUICKSTART

不到 1 分钟，装进你的 Omarchy

一键安装，快捷键就位，即刻享受行云流水的纯粹 GTD 体验。

STEP 1 · 核心引擎 (AUR / Cargo)
# AUR 预编译包 (推荐)
yay -S aur-horae-bin

# 或 Cargo 安装
cargo install horae
STEP 2 · Omarchy 状态栏插件
git clone https://github.com/zhaohang1205/horae_for_omarchy_shell.git
cd horae_for_omarchy_shell && ./install.sh
STEP 3 · Hyprland 快捷键 (~/.config/hypr/hyprland.conf)
# Super + T: 一秒闪念快速录入
bind = $mainMod, T, exec, horae -f

# Super + Shift + T: 呼出/聚焦 TUI 大本营
bind = $mainMod SHIFT, T, exec, omarchy-launch-or-focus-tui horae
