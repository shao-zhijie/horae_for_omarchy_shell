0-POLLING ARCHITECTURE

拒绝每秒轮询，真正事件驱动

传统桌面组件往往通过每秒钟 spawn 外部进程来刷新倒计时与任务，消耗大量 CPU 和唤醒能耗。Horae for Omarchy Shell 采用先进的时间戳本地推算与文件监听机制：

  • 时间戳本地运算：倒计时基于 session 开始与结束时间戳进行纯本地数学计算，完全不派生外部进程。
  • 毫秒级文件监听：通过 FileView 监听 pomo.json 与 horae.db，核心引擎有更新时瞬时响应。
  • 智能保底校准：60 秒慢速保底定时器捕获跨越周期的到期事件，始终保证数据绝对准确。

快速安装与配置

提供一键脚本自动化安装，或通过 Omarchy 官方 CLI 进行扩展集成。

前置依赖：安装 Horae CLI 引擎 
cargo install --git https://github.com/zhaohang1205/horae.git --rev c4c428bcff928758efb58d8687891e58b55d5c6a
方法 1：一键自动化配置安装（推荐） 
git clone https://github.com/zhaohang1205/horae_for_omarchy_shell.git
cd horae_for_omarchy_shell
./install.sh
方法 2：使用 Omarchy 插件命令添加 
omarchy plugin add https://github.com/zhaohang1205/horae_for_omarchy_shell.git --enable
🖱️ 状态栏鼠标手势与交互快捷键
Left Click 任务项
展开该任务的操作面板（开启专注、标记完成、延迟 1h、归档）
Left Click 番茄钟
快速唤起 Horae 闪念快速录入小窗 (horae --flash)
Right Click 组件区域
一键唤起或聚焦 Horae TUI 终端全功能控制面板
Double Click 番茄钟
直接停止并结算当前正在运行的番茄钟会话
